📥 Importer des eleves

Importe ton fichier eleves_complet.csv (code;classe;prenom;nom). Si le CSV contient une colonne code, les codes existants sont reutilises. Les noms restent sur ton appareil uniquement (RGPD).

📂 Glisse un fichier CSV ici ou clique pour choisir

👤 Charger les noms (fichier local)

Les noms ne sont pas enregistres dans Firebase (RGPD). Charge ton fichier DataEleves.csv pour afficher les noms. Ils restent sur ton appareil uniquement.

📂 Glisse DataEleves.csv ici ou clique

🛠️ Nettoyage (avance)

Utile uniquement pour supprimer d'anciens codes inutiles. Colle les codes a conserver (separes par des virgules).

Recuperer = ajouter ces codes a ta liste s'ils manquent.
Ne garder QUE = supprimer TOUS les autres codes (nettoyage).
